# dataprolms (frontend)

React + Vite app for Datapro LMS.

## New developer — start here

Open **[START_HERE.md](./START_HERE.md)**.

That file explains:

- where to begin (`src/`)
- which folders to copy / create
- frontend + backend file roles
- what to leave alone (packages, shell padding)

Also read:

- `../CODING_STANDARD.md` — naming
- `../REQUIREMENTS.md` — product modules
- `src/design_system/requirements.md` — CSS / shell rules
- `src/screen_starter/` — template for a new screen

## Run locally

```bash
npm install
npm run dev
```

API base URL comes from `.env` (`VITE_API_BASE`).
