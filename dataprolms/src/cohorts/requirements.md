# Cohorts

Employee screen for grouping programs.

| | |
|---|---|
| Who | Employee with `cohorts` view. Changes need edit. |
| Screen | `#/admin_dashboard/cohorts` |
| Must do | Create and edit cohorts. Create programs inside a cohort, or add an existing program. One cohort can hold many programs. Start and end dates belong to each program. Cohorts have no dates and no status. Uploading a cohort image writes that same URL onto every program in the cohort. Removing it deletes the file from storage and clears the image on the cohort and on every program in it. Cohort Details shows the program count, enrolled learners, the run dates across those programs, the description, and each program’s type, length, dates, and enrollment. |
| Done | Empty cohort list explains how to start. View-only cannot change data. Delete asks for confirmation. |
